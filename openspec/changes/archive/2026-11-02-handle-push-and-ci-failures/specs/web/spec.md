# Spec Delta

## ADDED Requirements

### Requirement: pushとCIの待ちの表示
一覧の画面と1件の画面は、待ちの理由 `push` と `ci` を、ほかの理由と同じく理由として表示しなければならない（MUST）。
理由が `ci` のとき、1件の画面は、返答の欄の近くに、返信すれば実行が再開し、自動で直す回数を数え直すことを示さなければならない（MUST）。
理由が `push` のとき、1件の画面は、返答の欄の近くに、トークンかリモートの設定を確かめる必要があることを示さなければならない（MUST）。

#### Scenario: CIの待ちを開く
- **WHEN** 理由が `ci` の待ちのissueを1件の画面で開く
- **THEN** 画面は、理由 `ci` と、返信で実行を再開できるという案内を表示し、承認のボタンを表示しない

#### Scenario: pushの待ちを一覧で見る
- **WHEN** 理由が `push` の待ちのissueがある
- **THEN** 一覧の画面のその行に、理由 `push` が表示される
