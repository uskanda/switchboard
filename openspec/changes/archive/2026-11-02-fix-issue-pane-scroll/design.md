# Design

## Context

動機はproposal.mdの「Why」を参照。今のコード（main、2006977）で、この設計を縛る点は次のとおり。

- 幅1024px以上では右のペイン（`main`）の中だけがスクロールし、それ未満ではページ全体がスクロールする。ヘッダ（`Header`）はどちらの幅でも`sticky top-0`で、高さは折り返しで変わる
- `IssuePane`は、issueが変わったことをeffectで受けて、キャッシュの内容に差し替えていた。そのため、新しいissueの参照と前のissueの内容で1回描く瞬間があった
- `Thread`の`shown`は、着手と順番待ちのコメントを1行に畳み、進捗のコメントは最新の1件だけを残す
- jsdomには`scrollIntoView`、IntersectionObserver、ResizeObserverが無い

## Goals / Non-Goals

**Goals:**

- 待ちと完了のissueを開いた直後に、返答に関わるカードが固定した見出しの直下に来る
- 開いている間の自動更新で、読んでいる位置を動かさない

**Non-Goals:**

- 実行中と順番待ちのissueを開いた直後のスクロール
- 一覧のペインのスクロール位置

## Decisions

### D1. 行き先を決める純粋な関数

`lib/scrollTarget.ts`に、スレッドの描き方と行き先の決め方を置く。`Thread`もここの`shown`を使う。

- `targetOf(detail)`：状態が実行中か順番待ちならnull。待ちならエージェントの最新のkindがwaitingのコメント、完了なら最新のkindがdoneのコメント、無ければ最後のカード。ほかはnull
- `cardsOf(comments)`：描くカードの一覧。識別子は書いた人、作成時刻、本文から作る。進捗が書き換わると、新しいカードになる
- `addedCards(prev, next)`：読み直しで加わったカードの番号

`Thread`は、各カードの`li`に元のコメントの番号を`data-index`で付ける。

### D2. 開いた直後のスクロールと知らせ

`IssuePane`は、issueが変わったことを描画の中で受けて、内容を差し替える。前のissueの内容で描く瞬間を無くし、開いた直後のスクロールを前のissueの内容で行わないためである。

detailが描かれるたびに、layout effectで次を行う。

- 前に描いたissueと違えば、開いた直後とみなし、`targetOf`があればそこへ`scrollIntoView({block: "start"})`する
- 同じissueで、まだ読み直しが届いていない（キャッシュを描いた）なら、届いた読み直しも開いた直後の一部とみなし、何もしない
- それ以外で`addedCards`が空でなければ、知らせを立てる。行き先は`targetOf`、無ければ加わった最初のカード

detailがキャッシュか読み直しかは、状態`fresh`に持つ。

知らせは`role="status"`の箱の中のボタンとし、`sticky bottom`で列の下に浮かせる。押すと行き先へスクロールして消える。行き先のカードはIntersectionObserverで見張り、いったん画面の外にあったものが画面に入ったら消す。知らせが出た時点で既に画面にあるカードは、自分のスクロールで入れたものではないので数えない。

### D3. 固定の見出し

「← 一覧へ」、参照、タイトル、状態の行を、1つの`sticky`の箱にまとめる。誤りのバナーと、一覧から消えたことの表示は固定しない。

- Headerは、自分の高さをResizeObserverで測り、ルートのCSS変数`--header-h`に入れる。見出しは幅1024px未満で`top-[var(--header-h)]`、それ以上で`top-0`にする
- 見出しの高さも`--pane-head-h`に入れる。スレッドのカードの`scroll-margin-top`は、幅1024px未満で両方の和、それ以上で見出しの高さにする
- 右のペインの上の余白をやめ、見出しの箱に上の余白を持たせる。固定した見出しの上に、スクロールした中身が見えないようにするためである
- 一番上にいるかは、記事の先頭に絶対配置した高さ1pxの目印で判定する。ヘッダの高さだけ上を狭めたIntersectionObserverで見張る。目印は見出しの外に置くので、タイトルを切って見出しの高さが変わっても、判定は行き来しない

ResizeObserverが無いときは変数を置かず、CSSは0pxで受ける。

## Risks / Trade-offs

- ［スクロールした後に画像や書体の読み込みでカードの位置がずれる］→画像はリンクとして出し、書体はOSのものなので、ずれは小さい
- ［タイトルを切ると見出しが低くなり、その分だけ中身が上に動く］→一番上から離れたときに1回だけ起きる
- ［jsdomでは位置を測れない］→位置と見た目は、ブラウザで幅1280pxと360pxを見て確かめる
