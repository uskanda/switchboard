# Proposal

## Why

2026-11-07のWeb受信箱の監査の残りの課題#181〜#185は、DESIGN.mdの改訂か仕様の判断が要るとして、前の2つの変更の対象外にした。どれも、スマホで読める量、送った後の手応え、デスクトップの空いた画面、進捗の読みやすさに関わり、毎日の操作で目に付く。

## What Changes

- #181：幅1024px未満でスクロールしたとき、1件の見出しを縮める。「←」とタイトル1行を1行目に並べ、状態の行は状態か理由のバッジと時間だけにする。参照、端末、フォージで開くリンクは、一番上に戻ると出る
- #182：返答を送った直後から、スレッドの末尾に送った返答の仮のカードを出す。フォージから読んだスレッドに同じ文の人のコメントが載ったら、仮のカードは消す。送ったissueが「処理中」のあいだは、状態の行に「処理中」を出す。返答を受けてエージェントが再開したら、実行中の案内の代わりに再開したことを伝える
- #183：幅1024px以上でissueを選んでいないとき、右のペインに一覧の4つの節の件数と、待ちの理由ごとの件数を出す
- #184：「プロジェクトでまとめる」と「新規issue」を、返答待ちの節の見出しと同じ行に置く。幅640px未満では、まとめるボタンの文言を「まとめる」に縮める
- #185：スレッドの進捗のカードは、最新の行のエージェントの発言を本文に出し、時刻、経過、ツールを本文の下に`muted`の1行で出す。すべての行は「進捗の記録」に畳んで出す

## Capabilities

### New Capabilities

- なし

### Modified Capabilities

- `web`：実行中の表示と、1件の表示の位置と固定の見出しの要件を変える。送った返答の仮のカード、何も選んでいない右のペイン、一覧の先頭のボタンの要件を足す

## Impact

- `web/ui/src/components/IssuePane.tsx`、`Thread.tsx`、`InboxList.tsx`
- `web/ui/src/pages/InboxLayout.tsx`
- `web/ui/src/lib/api.ts`（進捗のコメントの読み取り）
- `DESIGN.md`
- サーバーとAPIは変えない
