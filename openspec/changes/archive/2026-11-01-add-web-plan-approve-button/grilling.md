# grilling 記録: add-web-plan-approve-button

計画の承認待ち（`plan`）で、受信箱のWeb表示（`switchboard-web`）から、承認の語だけを1クリックで送れるようにする計画である（uskanda/switchboard#51）。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| ボタンを出す待ち | 理由が `plan` のときだけ。`plan-questions` では、承認の語が前の計画の承認になるので出さない。direct の待ちでは承認の語に意味が無いので出さない | Q1 A |
| 返答の欄に文があるとき | 押せなくする。欄が空（空白だけを含む場合も）のときだけ押せる。直しのつもりの文が承認として送られないようにする | Q2 A |
| 押したときの確認 | 挟まない。1クリックで送る。実装の実行は main への push もマージもできないので、誤って押しても取り返しがつく | Q3 A |
| ボタンの名前と並び | 「承認する（<承認の語> を送る）」を主のボタンにし、「返答を送る」を副のボタンにしてその左に置く。承認の語は設定の語を出す | Q4 A |
