# Proposal

## Why

計画の承認待ち（`plan`）では、計画に直しが無いときも、受信箱のWeb表示で返答の欄に `/ok` と打ってから「返答を送る」を押している。いちばん多い操作なのに、スマホでは記号の入力に手間がかかる。1クリックで承認できるようにする（uskanda/switchboard#51）。

## What Changes

- 理由が `plan` の待ちの1件の画面に、「承認する（<承認の語> を送る）」のボタンを主のボタンとして置く。押すと、承認の語だけを今の返答のPOSTで投稿する
- 返答の欄に空白以外の文があるとき、または待ちでないときは、このボタンを押せなくする
- 「返答を送る」は副のボタンにして、承認のボタンの左に並べる
- 計画の待ちの案内の文を、ボタンでも承認できることが分かる文に直す

## Capabilities

### New Capabilities

- なし

### Modified Capabilities

- `web`: 計画の待ちの表示に、承認のボタンを足す

## Impact

- `web/ui`：`IssuePane.tsx` のボタンと案内の文
- 核、`inboxapi`、`switchboard-web` のサーバーは変えない。送るのは、今も手で書ける承認の語のコメントで、承認の判定にそのまま合う
