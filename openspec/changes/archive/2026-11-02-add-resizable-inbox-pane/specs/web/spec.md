## ADDED Requirements

### Requirement: 一覧のペインの幅
幅1024px以上の間、WUIは、一覧のペインと1件のペインの境目を、`role="separator"`の要素として置かなければならない（MUST）。幅1024px未満の間、WUIは、境目を表示してはならない（MUST NOT）。
一覧のペインの幅は、既定で360pxとし、280px以上640px以下でなければならない（MUST）。ウィンドウの幅から480pxを引いた値が上限より小さいとき、WUIは、その値を上限としなければならない（MUST）。ただし、280pxを下回らせてはならない（MUST NOT）。
境目をドラッグしたとき、WUIは、一覧の幅をドラッグに合わせて変えなければならない（MUST）。
境目にフォーカスがある間、WUIは、左右の矢印キーで幅を16pxずつ変え、Homeで280px、Endで640pxにしなければならない（MUST）。いずれも上の範囲に収める。
境目をダブルクリックしたとき、WUIは、一覧の幅を360pxに戻さなければならない（MUST）。
一覧の幅を変えたとき、WUIは、その幅をブラウザに保存しなければならない（MUST）。次に開いたとき、WUIは、保存した幅を上の範囲に収めて使わなければならない（MUST）。保存した値が数でないときは、既定の幅を使う。
ウィンドウの幅が変わったとき、WUIは、保存した幅を新しいウィンドウの幅で範囲に収め直さなければならない（MUST）。

#### Scenario: 既定の幅で開く
- **WHEN** 幅1440pxのブラウザで、幅を保存していない状態で一覧の画面を開く
- **THEN** 一覧のペインは360pxで、境目の値も360である

#### Scenario: 矢印キーで動かす
- **WHEN** 境目にフォーカスを置き、右の矢印キーを2回、左の矢印キーを1回押す
- **THEN** 一覧の幅は376pxになり、その幅が保存される

#### Scenario: ドラッグで最小を下回る
- **WHEN** 境目を左へ大きくドラッグする
- **THEN** 一覧の幅は280pxで止まる

#### Scenario: ダブルクリックで戻す
- **WHEN** 幅500pxを保存した状態で開き、境目をダブルクリックする
- **THEN** 一覧の幅は360pxに戻る

#### Scenario: 狭いウィンドウ
- **WHEN** 幅640pxを保存した状態で、幅1024pxのブラウザで開く
- **THEN** 一覧の幅は544pxになり、右のペインに480pxが残る

#### Scenario: スマホの幅で開く
- **WHEN** 幅360pxのブラウザで一覧の画面を開く
- **THEN** 境目は出ず、横へのスクロールも出ない
