## ADDED Requirements

### Requirement: 完了のカードの操作
一覧が完了の行をカードで示す間、WUIは、PR/MRへのリンクとマージのボタンを、そのカードの枠の中に置かなければならない（MUST）。
一覧が完了の行をカードで示す間、WUIは、PR/MRへのリンクとマージのボタンを、1件へのリンクの中に置いてはならない（MUST NOT）。
一覧が完了の行をカードで示す間、WUIは、1件へのリンクとPR/MRの行の間を、`outline`の線で区切らなければならない（MUST）。
カードの形は、幅640px未満の一覧と、幅1024px以上の左のペインで使う。

#### Scenario: 完了のカードの操作は枠の中にある
- **WHEN** PR #9の番号とコミットを持つ完了のissueを選び、左のペインのカードを見る
- **THEN** そのカードの枠の中に、`PR #9`のリンクと「PR #9をマージ」のボタンがある

#### Scenario: 操作は1件へのリンクの外にある
- **WHEN** PR #9の番号とコミットを持つ完了のissueを選び、左のペインのカードを見る
- **THEN** `PR #9`のリンクと「PR #9をマージ」のボタンは、`aria-current="page"`の付いた1件へのリンクの中に無い
