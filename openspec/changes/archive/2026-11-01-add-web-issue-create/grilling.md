# grilling 記録: add-web-issue-create

受信箱のWeb表示（`switchboard-web`）から、設定にあるプロジェクトを選んで新しいissueを作れるようにする計画である（issue #40）。問いはissueのコメントで出し、返答もissueのコメントで受けた。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 認証の無いWUIから信頼済みのissueを作ること | 新しいADR-040で受け入れたリスクとして記録する。POSTには、返答と同じく、JSONと `Origin`、`Host` の検査をかける | Q1 = A |
| 付けるラベル | ready、plan、goから1つを選ばせる。初期値はready。ラベル名は設定の `labels.ready`、`labels.plan`、`labels.go` を使い、ハードコードしない | Q2 = B |
| 選べるプロジェクト | 設定にあるすべてのプロジェクト。担当の端末は問わない。選択肢には担当の端末の名前を出す | Q3 = A |
| 画面の置き場所と作ったあとの動き | 一覧のペインの上にボタンを置き、ダイアログで作る。作ったあとは一覧に残り、フォージのissueへのリンクを知らせとして出す | Q4 = B（推奨のAから変更） |
| 計画 | issueのコメント6562845139の計画を、6562852734の `/ok` で承認した | 承認 |
