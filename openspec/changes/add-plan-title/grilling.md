# grilling 記録: add-plan-title

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 計画の題をどこから取るか | A：計画の宣言に`title`（計画の題を1行で書く欄）を足し、計画の実行への指示にも書く | issue #86の計画の質問Q1（comment 6631219046）、回答はcomment 6633922178 |
| 質問の待ち（`plan-questions`）では何を出すか | A：質問の宣言にも同じ`title`（これから立てる計画の題）を求め、「計画：〈題〉」を出す | 同Q2、回答はcomment 6633922178 |
| 題を必須にするか | A：スキーマで`title`を必須にする。この変更の前に書かれたコメントには題が無いので、今までと同じ抜粋を出す | 同Q3、回答はcomment 6633922178 |
| 題をコメントのどこに書き、受信箱がどう拾うか | A：コメントの見出しのすぐ次に「**計画：** 〈題〉」（英語では「**Plan:** 〈title〉」）の段落を置く。受信箱と通知は`agent.Question`のまま、この段落を拾う | 同Q4、回答はcomment 6633922178 |
| 変えるところと確かめ方 | 計画（comment 6633954173）のとおり。宣言のスキーマ、コメントの書式、計画の実行への指示を変え、受信箱とUIのコードは変えない | 計画の承認はcomment 6633964894 |
