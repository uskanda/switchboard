## MODIFIED Requirements

### Requirement: 一覧の質問の冒頭
一覧の待ちの行は、質問の冒頭を、Markdownの太字とコードの記号を除いた文として表示しなければならない（MUST）。行頭の見出しの記号も除く。
計画の待ち（`plan`、`plan-questions`）で質問の冒頭が計画の題の段落のとき、一覧の待ちの行は「計画： 〈題〉」を表示する。

#### Scenario: 太字とコードを含む質問
- **WHEN** 質問の冒頭が ``1. **設定（`a.go`）** - `Agent` に…`` の待ちのissueがある状態で一覧を開く
- **THEN** その行には`1. 設定（a.go） - Agent に…`が出る

#### Scenario: 計画の待ちの題
- **WHEN** 理由が `plan` で、質問の冒頭が `**計画：** 設定の読み込みを分ける` の待ちのissueがある状態で一覧を開く
- **THEN** その行には`計画： 設定の読み込みを分ける`が出る
