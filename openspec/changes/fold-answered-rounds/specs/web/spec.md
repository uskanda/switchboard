# Spec Delta

## ADDED Requirements

### Requirement: 答え終わった質問のラウンドを畳む
1件の表示は、エージェントの最新の待ちより前の待ちのコメントを、続く人のコメントと合わせて1ラウンドとし、1行に畳まなければならない（MUST）。ラウンドは、次のエージェントの投稿の手前で終わる。着手と順番待ちの1行と、進捗のカードは、ラウンドに入れない。
1件の表示は、エージェントの最新の待ちのコメントを、issueのどの状態でも畳まずに出さなければならない（MUST）。
畳んだ1行は、エージェントの印、「答えた質問」、返答の件数（0件なら「返答なし」）、質問の日時を出さなければならない（MUST）。
畳んだ1行を押したとき、1件の表示は、そのラウンドの質問と返答のカードを開いて出さなければならない（MUST）。
開いたラウンドは、同じissueの読み直しでは開いたままでなければならない（MUST）。別のissueへ移ったとき、1件の表示は、ラウンドを畳み直さなければならない（MUST）。

#### Scenario: 答え終わった質問が2回ある
- **WHEN** 次の順にコメントがあるissueを開く：エージェントの質問・人の返答・着手・エージェントの質問・人の返答・着手・進捗・エージェントの質問
- **THEN** 古い2回の質問はそれぞれ「答えた質問・返答1件」の1行に畳まれる。着手の1行と進捗のカードはそのまま出る。最新の質問は開いたまま枠で目立つ

#### Scenario: 畳んだラウンドを開く
- **WHEN** 畳んだ1行を押し、そのあと同じissueの読み直しが届く
- **THEN** 質問と返答のカードが出て、読み直しのあとも開いたままである

### Requirement: 畳んだラウンドの中の行き先
開いた直後のスクロールの行き先か、知らせを押したときの行き先が、畳んだラウンドの中にあるとき、WUIは、そのラウンドを開いてからスクロールしなければならない（MUST）。

#### Scenario: 行き先が畳んだラウンドの中にある
- **WHEN** 実行中のissueを開いたまま、畳んだラウンドの中の人の返答を書き換えた読み直しが届き、知らせを押す
- **THEN** そのラウンドが開き、書き換わった返答のカードへスクロールする
