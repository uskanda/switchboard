# grilling 記録: fold-answered-rounds

issue `gh:uskanda/switchboard` #85の計画である。計画の質問が何ラウンドも続くと、1件の表示のスレッドは長くなる。答え終わった古い質問も、まだ答える必要があるように見える。grillingは、issueのコメントで計画を先に立てるモードとして行った。質問はコメント6583905007、回答はコメント6584249652にある。計画はコメント6584292102で、コメント6584411503の `/ok` で承認された。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 1ラウンドとして畳む範囲 | エージェントの古い質問のコメントと、その後に続く人のコメント（次のエージェントの投稿の手前まで）。着手の1行と進捗のカードは、今と同じくラウンドの外に出す | Q1（A） |
| 「答え終わった」とみなす質問 | エージェントの最新の質問以外すべて。最新の質問は、待ち・実行中・完了のどの状態でも開いたまま出し、枠の強調も残す | Q2（A） |
| 畳む対象のエージェントの待ち | エージェントの待ちのコメント（kind waiting）はすべて同じように畳む。計画の質問、計画の提示、失敗のあとの待ちを区別しない | Q3（A） |
| 畳んだ1行に出す内容 | エージェントの印、「答えた質問」、質問の日時、返答の件数（例: 「エージェント 答えた質問・返答1件 11/2 10:15 ▸」）。返答が0件なら「返答なし」 | Q4（A）、計画 |
| 開け閉めの仕組みと状態の保ち方 | ネイティブの `<details>`/`<summary>`。開いた状態は同じissueの読み直しでは保ち、別のissueへ移ると畳み直す。スクロールや知らせの行き先が畳んだラウンドの中にあるときは、開いてからスクロールする | Q5（A） |
