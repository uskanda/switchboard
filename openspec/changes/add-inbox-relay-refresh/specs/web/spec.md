## ADDED Requirements

### Requirement: 自動更新の速さの表示
知らせの接続がつながっている間、WUIは、ヘッダの自動更新の表示を、一覧の `relay` で分けなければならない（MUST）。`connected` なら「自動更新中（即時）」、`disconnected` なら「自動更新中（N秒ごと）」とする。Nは一覧の `refresh_interval_seconds` である。空なら「自動更新中」とする。
知らせの接続が切れている間、WUIは、中継の状態にかかわらず、切れていて再接続を試みていることを示さなければならない（MUST）。
WUIは、中継の状態で、ヘッダの状態の点の印を変えてはならない（MUST NOT）。

#### Scenario: 中継が切れる
- **WHEN** 画面を開いている間に、中継が止まる
- **THEN** ヘッダの表示が「自動更新中（即時）」から「自動更新中（30秒ごと）」に変わり、点は塗られたままである
