# Proposal

## Why

Web UIの使いやすさの監査で、重要度は低いが手間の小さい不便が7つ見つかった（issue #90）。たとえば、待ちの件数が目立たない。時間が何の時間か分からない。進捗の行が内部のツール名を並べる。これらをまとめて直す。

## What Changes

- ヘッダの待ちの件数を、待ちが1件以上あるとき`attention`の色の太字にする
- 一覧のカードと1件の見出しの状態の行で、時間を「2分経過」「5分前から待ち」のような文で出す
- 一覧の実行中の行には、進捗の行のうちエージェントの最新の発言だけを出す。無ければ「作業しています」とする（これまでの「進捗はまだありません」をやめる）
- デスクトップで何も選んでいないとき、右のペインに最も古い待ちへの案内を出す
- 設定の画面に見出し「設定」を置き、問題の無いプロジェクトを1行にまとめる
- 指示の欄に未保存の印を出し、未保存の文を画面を移っても残す。再読み込みの前にはブラウザの確認を出す
- 新規issueの「プロジェクトの設定どおりに始める」に、選んだプロジェクトが計画から始めるかを補う。そのため、issueを作れる先の一覧の項目に`plan_first`を足す
- 一覧のカードのタイトルを2行で切る

## Capabilities

### New Capabilities

- なし

### Modified Capabilities

- `web`：画面（右のペインの案内）、設定の画面、設定の画面のプロジェクトの節、新規issueのダイアログ、実行中の行の進捗を変える。ヘッダの待ちの件数、時間の文、カードのタイトル、指示の欄の未保存の印の要件を足す
- `inbox-api`：issueを作れる先の一覧の項目に`plan_first`を足す

## Impact

- Go：`inboxapi.IssueTarget`に`plan_first`を足す（足すだけで、古いクライアントは無視する）。`internal/inboxserve`が設定の値を入れる
- Web UI：`Header`、`InboxList`、`IssuePane`、`InboxLayout`、`SettingsPage`、`ProjectsSection`、`NewIssue`、`lib/api.ts`。指示の下書きの`lib/instructionDrafts.ts`を新しく作る
- DESIGN.md：ヘッダ、色、タイプ、レイアウト、一覧の行、1件の見出し、設定の画面、プロジェクトの節、新規issue、指示の節、Doの決まり
