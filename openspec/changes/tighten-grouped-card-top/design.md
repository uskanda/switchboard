# Design

## Context

カードは、1件へのリンクが`p-lg`で四辺に16pxの余白を持つ。まとめない表示では、1行目に参照（`mono-sm`、行の高さ1.4）とアイコンが来る。まとめる表示では、1行目がタイトル（`body-md`の15px、行の高さ1.6）になり、文字の上に約4.5pxの空きが足される。下の行（`label-md`、行の高さ1.4）の空きは約2.6pxなので、上だけが空いて見える。

## Goals / Non-Goals

**Goals:**
- まとめる表示のカードで、タイトルの文字の上の空きを左右の余白（16px）に近づける

**Non-Goals:**
- まとめない表示のカード、表の行、カードの間の余白は変えない

## Decisions

- まとめる表示のときだけ、リンクの余白を`px-lg pt-md pb-lg`にする。文字の上の空きは約16.5pxになり、左右とそろう
  - 代案の`pt-sm`（8px）は、文字の上が約12.5pxになり、左右より狭いので採らない
  - 代案の負のマージンやタイトルの行の高さの変更は、`spacing`の値だけを使うDESIGN.mdの決まりから外れるので採らない
- 完了のカードのPR/MRの行（線より下）は、1件へのリンクの外にあり、余白を変えない

## Risks / Trade-offs

- [ブラウザで撮った画面での確認ができていない] → 寸法は行の高さの値から計算した。テストはまとめる表示とまとめない表示で余白のクラスを確かめる
