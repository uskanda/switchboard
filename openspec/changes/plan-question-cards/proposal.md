# Proposal

## Why

計画の質問の待ち（`plan-questions`）のWeb表示では、問いの境目が見出し1行と余白だけで示され、前の問いの推奨の段落が次の問いの題に続いて見える（#189）。これまでのgrillingは1ラウンドが平均3.8問、本文の中央値が約2,000字で、PRODUCT.mdの「通知から開いて1分かからずに返答を送れる」には読む量が多い。

## What Changes

- 最新の質問のカードの中で、問いを1つずつ `outline` の枠のカードにする。題の前に、番号とラウンドの中の位置（`Q5 1/2`）を付ける
- 推奨の理由を、問いの最後から、推奨の選択肢の行のすぐ下へ移す
- 組ごとの「選ばない（補足で答える）」のラジオボタンをやめる。補足の欄に「選択肢を選ばず、補足だけで答える」のチェックボックスを置く。補足の欄を開くボタンの文言を「Qnに別の答えや補足を書く」に変える
- 返答の欄の送る文の上に、問いごとの状態（推奨どおり、推奨と違う、補足だけ、未回答、選択済み）をチップで並べる。チップを押すと、その問いへ移る
- 2ラウンド目からは、今の周期の前のラウンドで決まったことを、最新の質問のカードの先頭に一覧で出す
- 質問のコメントの冒頭の、エージェントが調べたことの段落を折りたたむ
- DESIGN.mdの「計画の質問のカード」を、この形に書き改める

## Capabilities

### New Capabilities

- なし

### Modified Capabilities

- `web`: 計画の質問の描き方（問いのカード、推奨の理由の位置、選ばない答え方、補足の欄）、問いの状態のチップ、前のラウンドで決まったことの一覧、調べたことの折りたたみ

## Impact

- `web/ui/src/components/PlanQuestions.tsx`：問いのカード、推奨の理由、チェックボックス、決まったことの一覧、調べたことの折りたたみ
- `web/ui/src/lib/planQuestions.ts`：冒頭の分割、問いの状態、前のラウンドの答えの読み取り
- `web/ui/src/components/IssuePane.tsx`：チップの置き場所と、押したときのスクロールとフォーカス
- DESIGN.md
- 核（`switchboard`）、受信箱のAPI、エージェントのプロンプトとコメントの形は変えない
