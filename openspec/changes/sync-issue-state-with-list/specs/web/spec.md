## ADDED Requirements

### Requirement: 一覧と状態が違うあいだの知らせ
1件の画面は、次の条件がすべてそろうあいだ、状態の行に「フォージから今読んだ状態です。一覧は更新を待っています」と出さなければならない（MUST）。

- 1件の状態と一覧の行の状態が違う。状態は実行中、順番待ち、完了、待ちの4つで比べ、理由は比べない
- 表示している詳細が、キャッシュではなく今回読んだものである
- 1件を読み直している最中でない
- 一覧にそのissueの行がある

知らせは、読み上げられるよう`role="status"`で出さなければならない（MUST）。

#### Scenario: 一覧が古い
- **WHEN** 一覧で順番待ちのissueを開き、読んだ詳細が実行中である
- **THEN** 状態の行に「フォージから今読んだ状態です。一覧は更新を待っています」が出る

#### Scenario: 一覧が追いつく
- **WHEN** 知らせが出ているあいだに、一覧の行が実行中になった一覧が届く
- **THEN** 知らせは消える

#### Scenario: 状態が同じ
- **WHEN** 一覧で待ちのissueを開き、読んだ詳細も待ちである
- **THEN** 知らせは出ない

#### Scenario: 読み直しの最中
- **WHEN** 状態が違う詳細を表示したまま、1件を読み直している
- **THEN** 知らせは出ず、「更新を取得中」が出る
