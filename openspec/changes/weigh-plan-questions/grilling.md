# grilling 記録: weigh-plan-questions

計画の質問の重みと順番を整え、所有者が読む量を減らす計画である（issue `gh:uskanda/switchboard` #191）。#190（`structured-plan-questions`）の宣言の形の上に作る。

背景は次のとおりである。これまでのgrillingで返答のあった約200問のうち、約9割は推奨どおりに答えた。推奨と違う答えは16問で、そのうち5問はQ1（範囲や方向を決める問い）だった。直近の11件では、5件でQ1を変えている。

決める前に、今の仕組みについて次の事実を確かめた。

- 計画の実行への指示には、選択肢を「選んだときに何が変わるか」で1行に書く決まりが、#190で入っている。
- 指示には、まだ答えのない問いに左右される問いを後のラウンドに回す決まりが既にある。
- 計画の本文には、計画が拠って立つ決定を書く決まりがある。推奨どおりに答えた問いは、計画でもう一度読むことになる。
- `summary` は「1〜2文」の決まりで、Web表示では「エージェントが調べたこと」として折りたたまれる（#189）。
- 計画の段階のラウンドの数に上限は無い。質問のコメントのマーカーの `q=` は最後の問いの番号を持ち、次のラウンドはその次から番号を振る。
- Web表示は、返答の文に、すべての問いを `Q<n> <題>: <答え>` の1行ずつで書く。「これまでに決まったこと」の一覧は、この行を読み返して作る。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 確認だけの問いの置き場所 | 問いのまま残し、問いごとに「判断が要る」か「確認だけ」かの印を付けさせる。Web表示は確認だけの問いを「推奨どおりで進めるもの」にまとめる。計画の前提に移す案は、確認の項目が計画の段階まで出てこないので採らない | 第1ラウンド Q1 |
| 変更の範囲 | 問いの重みとWeb表示のまとめ方、範囲の問いを先に聞くこと、問いの書き方の3つを1つの変更にする | 第1ラウンド Q2 |
| 範囲や方向を決める問いを先に聞く仕組み | プロンプトで指示するだけにする。答えによってほかの問いの選択肢が変わる問いがあれば、そのラウンドではその問いだけを聞かせる。ラウンドが1回増えることは受け入れる | 第1ラウンド Q3 |
| 問いの書き方の決まり | 本文は問いを1文で書き、判断に要る事実を、その後に3つまでの短い箇条書きで書かせる。調べた根拠は `summary` に書かせ、「1〜2文」の決まりは外す。コードの名前は初めて出たところで括弧の中で説明させる。どれもプロンプトの指示だけにし、switchboardは検査しない | 第1ラウンド Q4 |
| 問いの印の形 | 各問いに必須の `weight` を足し、`decision`（判断が要る）か `check`（確認だけ）とする。確認だけの問いの基準は、推奨の答えがissue、コード、既存の決まりから導けて、ほかの選択肢を選ぶ理由が見当たらないこととし、プロンプトに書く | 第2ラウンド Q5 |
| フォージのコメントでの並べ方 | 判断が要る問いを先に並べて番号を振る。続けて「推奨どおりで進めるもの」の見出しを置き、その下に確認だけの問いを全文のまま続きの番号で書く。フォージの上では折りたたまない | 第2ラウンド Q6 |
| Web表示のまとめ方とPRODUCT.mdの原則3 | 「推奨どおりで進めるもの（n件）」の節に、確認だけの問いを1行ずつ（番号、題、推奨の選択肢の文）並べる。行を押すとその問いのカードが開き、選び直せる。原則3に確認だけの問いの例外を足し、ADRを書く | 第2ラウンド Q7 |
| 問いの状態のチップと返答の文 | チップは判断が要る問いにだけ出し、確認だけの問いには「推奨どおり n件」のチップを1つ出す。選び直した確認だけの問いには、その問いのチップを別に出す。返答の文は今と同じく、すべての問いを1行ずつ書く | 第2ラウンド Q8 |
| すべての問いが確認だけになるとき | 問いを出さずに計画を出させ、確認だけの事項は計画の拠って立つ決定に書かせる。`plan_first: auto` でも、実装へ飛ぶ `implement` にはさせない | 第2ラウンド Q9 |
| 見出しと行の文言 | 見出しは「推奨どおりで進めるもの」（英語は "Going ahead as recommended"）。Web表示の節の見出しには件数を付ける。行は「Q7 題 — B：選択肢の文」の形にする。まとめたチップは「推奨どおり 3件」（"As recommended: 3"）とする | 第3ラウンド Q10 |
| 確認だけの問いを選び直したときの表示 | 行はその場に残し、行の印を「推奨と違う」に変える。開いたカードは開いたままにする | 第3ラウンド Q11 |
| 1ラウンドの問いの数の上限 | 上限は設けない | 第3ラウンド Q12 |
| 効果を測るための記録 | 新しい記録は足さない。確認だけの問いは見出しでコメントの上から見分けられるので、後から数え直せる | 第3ラウンド Q13 |
| 作業のブランチ | `structured-plan-questions` から切った `weigh-plan-questions` で進める。#195がmainへマージされたら、このPRはmainへ付け替える。マージ済みのブランチへマージすることは避ける | 会話中に確認（第3ラウンドのまとめ） |
| 範囲や方向を決める問いの図 | 必須にはしない。宣言に範囲の問いの印が無く、switchboardは検査できないからである。プロンプトの図の目安に、範囲や方向を決める問いでは何が含まれて何が外れるかを図で示すと伝わりやすい、という1行を足す（#190の記録で#191に先送りした項目） | 第4ラウンド Q14 |
