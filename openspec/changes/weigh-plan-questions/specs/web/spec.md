## MODIFIED Requirements

### Requirement: 問いのカード
計画の質問を表示する間、1件の表示は、最新の質問のコメントの判断が要る問いを、1つずつ枠で囲んだカードとして描かなければならない（MUST）。
計画の質問を表示する間、1件の表示は、問いのカードの題の前に、問いの番号と、ラウンドの中の位置（`<何問目>/<問いの数>`）を表示しなければならない（MUST）。問いの数には、確認だけの問いも数える。

#### Scenario: 2ラウンド目の問い
- **WHEN** Q5とQ6の質問のコメントで待っているissueを開く
- **THEN** 2枚の問いのカードが表示され、題の前にそれぞれ `Q5 1/2` と `Q6 2/2` が表示される

#### Scenario: 確認だけの問いのあるラウンド
- **WHEN** 判断が要るQ5とQ6、`推奨どおりで進めるもの` の見出し、確認だけのQ7とQ8の順の質問のコメントで待っているissueを開く
- **THEN** 問いのカードはQ5とQ6の2枚で、題の前にそれぞれ `Q5 1/4` と `Q6 2/4` が表示される

### Requirement: 問いの状態のチップ
計画の質問の答えを選べる間、1件の表示は、送る文の上に、判断が要る問いごとに1つのチップを問いの順に並べなければならない（MUST）。チップには、問いの番号と状態を表示する。
1件の表示は、問いの状態を、次の順に当てはまる最初のものとしなければならない（MUST）。
- 補足だけ：補足を書いた問いのうち、「選択肢を選ばず、補足だけで答える」を入れた問いと、組の無い問い
- 未回答：補足が空で、組が無いか、選択の無い組がある問い。「選択肢を選ばず、補足だけで答える」を入れて補足が空の問いも、送る文が `回答なし` になるのでここに入る
- 推奨と違う：推奨にラベルのある組のどれかで、推奨と違う選択肢を選んだか、何も選んでいない問い
- 推奨どおり：推奨にラベルのある組がすべて推奨の選択肢を選んでいる問い
- 選択済み：どの組にも推奨のラベルが無い問い
補足を書いた問いでは、状態が補足だけでないとき、1件の表示は、チップの状態のあとに「＋補足」を表示しなければならない（MUST）。
1件の表示は、状態が推奨どおりで補足の無い確認だけの問いを、1つのチップにまとめなければならない（MUST）。まとめたチップには `推奨どおり 〈件数〉件`（英語では `As recommended: 〈件数〉`）と表示し、ほかのチップの後に置く。
状態が推奨どおりでないか補足のある確認だけの問いには、1件の表示は、その問いのチップを、判断が要る問いのチップの後に問いの順で並べなければならない（MUST）。
判断が要る問いのチップを押したとき、1件の表示は、その問いのカードを固定の見出しのすぐ下までスクロールし、カードの題にフォーカスを移さなければならない（MUST）。
確認だけの問いのチップを押したとき、1件の表示は、その問いの行を開き、行を固定の見出しのすぐ下までスクロールし、行にフォーカスを移さなければならない（MUST）。
まとめたチップを押したとき、1件の表示は、推奨どおりで進めるものの節を固定の見出しのすぐ下までスクロールし、節の見出しにフォーカスを移さなければならない（MUST）。

#### Scenario: 開いた直後
- **WHEN** すべての問いに推奨の選択肢がある計画の質問の待ちを開く
- **THEN** 送る文の上に、判断が要る問いのチップが「推奨どおり」で並ぶ

#### Scenario: 推奨と違う案を選ぶ
- **WHEN** 推奨がAのQ2で、Bを選ぶ
- **THEN** Q2のチップは「推奨と違う」になる

#### Scenario: 補足を書く
- **WHEN** 推奨のAを選んだままのQ3で、補足に文を書く
- **THEN** Q3のチップは「推奨どおり＋補足」になる

#### Scenario: 推奨にラベルの無い問い
- **WHEN** 推奨にラベルの無い組だけを持つQ4の問いを開き、そのあとでBを選ぶ
- **THEN** Q4のチップは、開いた直後は「未回答」、Bを選んだあとは「選択済み」になる

#### Scenario: 補足だけで答える問い
- **WHEN** Q5で「選択肢を選ばず、補足だけで答える」を入れ、そのあとで補足に文を書く
- **THEN** Q5のチップは、入れた直後は「未回答」、補足を書いたあとは「補足だけ」になる

#### Scenario: チップを押す
- **WHEN** Q2のチップを押す
- **THEN** Q2の問いのカードが固定の見出しのすぐ下に来るまでスクロールし、Q2の題にフォーカスが移る

#### Scenario: 確認だけの問いのまとめたチップ
- **WHEN** 判断が要るQ5とQ6、確認だけのQ7からQ9の待ちを開く
- **THEN** チップは、Q5、Q6、`推奨どおり 3件` の順に並ぶ

#### Scenario: 確認だけの問いを選び直す
- **WHEN** 確認だけのQ7からQ9の待ちで、推奨がBのQ8でCを選ぶ
- **THEN** Q8のチップが「推奨と違う」で別に出て、まとめたチップは `推奨どおり 2件` になる

#### Scenario: 確認だけの問いのチップを押す
- **WHEN** 確認だけのQ8を選び直したあとで行を閉じ、Q8のチップを押す
- **THEN** Q8の行が開いて固定の見出しのすぐ下に来るまでスクロールし、Q8の行にフォーカスが移る

#### Scenario: まとめたチップを押す
- **WHEN** `推奨どおり 3件` のチップを押す
- **THEN** 推奨どおりで進めるものの節が固定の見出しのすぐ下に来るまでスクロールし、節の見出しにフォーカスが移る

## ADDED Requirements

### Requirement: 推奨どおりで進めるもの
最新の質問のコメントに `推奨どおりで進めるもの` の見出しがあるとき、1件の表示は、その見出しより後の問いを確認だけの問いとして読まなければならない（MUST）。英語の見出しは `Going ahead as recommended` である。
確認だけの問いがあるとき、1件の表示は、判断が要る問いのカードの後に、確認だけの問いの節を置かなければならない（MUST）。節の見出しは `推奨どおりで進めるもの（〈件数〉件）`（英語では `Going ahead as recommended (〈件数〉)`）とする。
1件の表示は、節の中に、確認だけの問いを1問1行で、問いの順に並べなければならない（MUST）。
最新の質問のコメントにその見出しが無いとき、1件の表示は、すべての問いを判断が要る問いとして描かなければならない（MUST）。

#### Scenario: 確認だけの問いの節
- **WHEN** 判断が要るQ5、見出し、確認だけのQ6からQ8の順の質問のコメントで待っているissueを開く
- **THEN** Q5のカードの後に `推奨どおりで進めるもの（3件）` の節があり、Q6、Q7、Q8の3行が並ぶ

#### Scenario: 見出しの無いコメント
- **WHEN** `推奨どおりで進めるもの` の見出しの無い、Q1からQ3の質問のコメントで待っているissueを開く
- **THEN** 3枚の問いのカードが表示され、推奨どおりで進めるものの節は無い

### Requirement: 確認だけの問いの行
1件の表示は、確認だけの問いの行に、問いの番号、題、選んでいる選択肢のラベルと文を表示しなければならない（MUST）。開いた直後は、推奨の選択肢を選んでいる。
状態が推奨どおりでないか補足があるとき、1件の表示は、行に問いの状態のチップと同じ状態の語を表示しなければならない（MUST）。
行を押したとき、1件の表示は、行のすぐ下に、その問いのカード（本文、図、選択肢、推奨の理由、補足の欄）を開かなければならない（MUST）。開いた行をもう一度押すと、カードを閉じる。開いたカードには、題の行とラウンドの中の位置を表示しない。行がその代わりになる。
確認だけの問いの答えを変えたとき、1件の表示は、その行を節の中の同じ位置に残さなければならない（MUST）。開いたカードは開いたままにする。
行は、キーボードで押せて、開いているかどうかを支援技術に伝えなければならない（MUST）。

#### Scenario: 開いた直後の行
- **WHEN** 推奨がBで、Bの文が「今のまま残す」の確認だけのQ7「ログの形式」を持つ待ちを開く
- **THEN** 行は `Q7 ログの形式 — B：今のまま残す` を表示し、状態の語は無い

#### Scenario: 行を押して選び直す
- **WHEN** 確認だけのQ7の行を押し、開いたカードでCを選ぶ
- **THEN** Q7の行は節の中の同じ位置に残り、Cのラベルと文、「推奨と違う」を表示し、カードは開いたままである

#### Scenario: キーボードで開く
- **WHEN** 確認だけのQ7の行にフォーカスを移し、Enterを押す
- **THEN** Q7のカードが開き、行は開いていることを支援技術に伝える
