# grilling 記録: show-forge-badge-in-refs

issue `gh:uskanda/switchboard` #70の変更である。WUIの参照から「gh:」「gl:」のプレフィックスを外し、参照の後ろにフォージのラベルを置く。計画の段階で、エージェントがissueのコメントで質問し、issueの持ち主が答えた。そのやり取りをここに写す。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 変える範囲 | Web UIの表示だけを変える。CLIの出力、入力の形式（`gh:owner/repo`）、URL、APIの`ref`は今のままにする | issue #70 第1ラウンド Q1（A） |
| ラベルの見た目 | フォージごとに色を分けたバッジにする。表記は「GitHub」「GitLab」 | issue #70 第1ラウンド Q2（C） |
| ラベルを置く位置 | プレフィックスを外した参照のすぐ後ろに置く | issue #70 第1ラウンド Q3（A） |
| バッジを置けない箇所 | `<option>`は「o/r GitHub（担当：desk）」のように、フォージの名前を文字で参照の後ろに書く。指示の欄の名前とトーストは参照とバッジにする | issue #70 第1ラウンド Q4（A） |
| バッジの配色 | 既存の色と重ならない淡い地にする。GitHubは青みの灰色（地 #E6EBF1、文字 #24292F）、GitLabは紫（地 #EEE8FB、文字 #5B3BB0） | issue #70 第2ラウンド Q5（A） |
| 計画の承認 | 計画を変えずに承認 | issue #70 コメント6579167258（`/ok`） |
