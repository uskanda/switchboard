# Spec Delta

## ADDED Requirements

### Requirement: 設定の画面の実装の実行だけの指示
設定の画面は、全体と各プロジェクトについて、計画用と実装用の欄に加え、実装の実行だけの指示の欄を並べなければならない（MUST）。
その欄は、ほかの欄と同じように、欄ごとに保存でき、誤りを欄ごとに示す。

#### Scenario: 実装の実行だけの欄に保存する
- **WHEN** 設定の画面で `gh:uskanda/switchboard` の実装の実行だけの欄に指示を書いて保存する
- **THEN** その欄だけが保存され、同じ対象の計画用と実装用の欄は変わらない
