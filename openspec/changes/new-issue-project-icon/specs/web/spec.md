## MODIFIED Requirements

### Requirement: 新規issueのプロジェクトの選択肢
新規issueのダイアログのプロジェクトの欄は、閉じた欄と開いた一覧の各選択肢に、次の4つをこの順に表示しなければならない（MUST）。プロジェクトのアイコン、プレフィックスを外した参照、フォージのバッジ、担当の端末である。
各選択肢の読み上げの名前は、「o/r GitHub（担当：desk）」の形でなければならない（MUST）。アイコンは読み上げに含めない。
一覧は、キーボードでも開き、選べなければならない（MUST）。
一覧が開いているときのEscapeは、一覧だけを閉じなければならない（MUST）。ダイアログを閉じてはならない（MUST NOT）。

#### Scenario: 選択肢を見る
- **WHEN** 端末`desk`の担当する`gh:o/r`がある端末で、新規issueのダイアログを開き、プロジェクトの一覧を開く
- **THEN** 一覧に「o/r GitHub（担当：desk）」という名前の選択肢が出て、`o/r`の前に`gh:o/r`のアイコン、後ろにGitHubのバッジが置かれる

#### Scenario: 閉じた欄のアイコン
- **WHEN** 新規issueのダイアログで`gh:o/r`が選ばれている
- **THEN** 閉じた欄に、`gh:o/r`のアイコン、`o/r`、GitHubのバッジ、「（担当：desk）」が並ぶ

#### Scenario: キーで選ぶ
- **WHEN** プロジェクトの欄にフォーカスを当て、↓で一覧を開き、↓とEnterで2つ目のプロジェクトを選ぶ
- **THEN** 一覧が閉じ、欄が2つ目のプロジェクトになり、作成するとそのプロジェクトにissueが作られる

#### Scenario: Escapeで一覧だけを閉じる
- **WHEN** プロジェクトの一覧が開いているときにEscapeを押す
- **THEN** 一覧が閉じ、ダイアログは開いたままで、フォーカスはプロジェクトの欄に戻る
