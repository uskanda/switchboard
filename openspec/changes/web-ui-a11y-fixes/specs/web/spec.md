## ADDED Requirements

### Requirement: Markdownの見出しの段
WUIは、issueの本文とコメントのMarkdownの見出しを、2段下げた見出しとして描かなければならない（MUST）。h1はh3、h2はh4、h3はh5で描き、h4からh6はh6で描く。

#### Scenario: コメントの見出しを描く
- **WHEN** コメントに`# a`、`## b`、`### c`、`#### d`、`###### e`の見出しがある
- **THEN** それぞれh3、h4、h5、h6、h6の見出しとして描かれ、h1とh2の見出しは描かれない

### Requirement: 計画の質問の題の見出し
WUIは、計画の質問の題を、h3の見出しとして描かなければならない（MUST）。

#### Scenario: 計画の質問を開く
- **WHEN** 計画の質問が残っているissueを開く
- **THEN** 問いの題はh3の見出しで描かれ、問いの節の名前になる
- **AND** 問いの本文にある`##`の見出しはh4で描かれる

### Requirement: マージのダイアログの最初のフォーカス
マージの確認のダイアログを開いたとき、WUIは、「やめる」のボタンにフォーカスを当てなければならない（MUST）。

#### Scenario: マージのボタンを押す
- **WHEN** 完了したissueの「マージ」のボタンを押してダイアログを開く
- **THEN** フォーカスは「やめる」のボタンにある

### Requirement: 一覧のカードのフォーカスの輪郭
WUIは、一覧のカードのフォーカスの輪郭を、カードから離して描かなければならない（MUST）。

#### Scenario: 選んでいるカードにフォーカスを当てる
- **WHEN** 幅1024px以上の画面で、選んでいるカードにキーボードでフォーカスを当てる
- **THEN** 選んでいることを示す枠と、カードから離れたフォーカスの輪郭が二重に見える
