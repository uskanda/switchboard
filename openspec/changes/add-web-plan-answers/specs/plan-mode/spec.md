## MODIFIED Requirements

### Requirement: 計画の実行の指示
計画の実行のsystem promptに、エージェントは次の指示を書かなければならない（MUST）。
コードとファイルを変えないこと。決まっていない設計上の判断を洗い出し、今答えられるものをすべて1ラウンドで、推奨の答えを付けて聞くこと。事実は自分で調べ、判断だけを聞くこと。決めることが無くなったら計画を出すこと。
選択肢のある問いでは、選択肢を1行に1つ、`A:` のようにラベルを付けて書くこと。

#### Scenario: 計画の実行を始める
- **WHEN** 計画の実行を始める
- **THEN** `--append-system-prompt-file` のファイルに、コードを変えないことと、推奨の答えを付けて一度に聞くことが書かれている

#### Scenario: 選択肢の書き方
- **WHEN** 計画の実行を始める
- **THEN** `--append-system-prompt-file` のファイルに、選択肢を1行に1つ、ラベルを付けて書くことが書かれている
