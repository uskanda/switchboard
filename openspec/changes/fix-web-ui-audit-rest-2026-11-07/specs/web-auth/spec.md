## ADDED Requirements

### Requirement: ログインの後の戻り先
ログインの画面を一覧と `/login` 以外のページで出したとき、Web表示は、ログインのリンクに今のパスと問い合わせを `next` として付けなければならない（MUST）。
`/auth/login` が、この受信箱のパスである `next` を受けたとき、Web表示は、それを10分のあいだcookieに覚えなければならない（MUST）。
`/auth/callback` がセッションを作ったとき、Web表示は、覚えたパスへリダイレクトし、cookieを消さなければならない（MUST）。覚えたパスが無いときは `/` へリダイレクトする。
この受信箱のパスとは、`/` で始まる1024バイト以下の文字列である。ただし、`//` か `/\` で始まるものと、制御文字を含むものは除く。Web表示は、それ以外の `next` へリダイレクトしてはならない（MUST NOT）。

#### Scenario: 通知から開いた1件でログインする
- **WHEN** ログインしていないブラウザで `/issue/<ref>?action=merge` を開き、GitLabでログインする
- **THEN** ログインの後に `/issue/<ref>?action=merge` が開く

#### Scenario: 外部のサイトを戻り先に渡す
- **WHEN** `/auth/login?next=//evil.example/` を開いてログインする
- **THEN** cookieは作られず、ログインの後は `/` が開く

### Requirement: ログアウトのときの処理中の印
ログアウトが成功したとき、およびセッション切れを受けたとき、Web表示は、このタブの「処理中」の印を消さなければならない（MUST）。同じタブで次にログインした人に、前の人が頼んだ操作の印を見せないためである。

#### Scenario: ログアウトして別の人がログインする
- **WHEN** 返答を送った直後にログアウトする
- **THEN** タブの「処理中」の印は消える
