## ADDED Requirements

### Requirement: 送信中に別のissueへ移ったときの返答
返答の送信中に別のissueへ移ったとき、WUIは、送信の結果を送った先のissueにだけ反映しなければならない（MUST）。
送信の結果が届いたとき、WUIは、今表示しているissueの返答の欄、選択、送信済みの表示、誤りの表示を変えてはならない（MUST NOT）。
送った先のissueへの送信が成功したとき、WUIは、そのissueの書きかけを消さなければならない（MUST）。失敗したとき、WUIは、失敗をトーストで知らせ、そのissueの書きかけを残さなければならない（MUST）。
返答の欄を送信中として押せなくするのは、送信中のissueを表示している間だけでなければならない（MUST）。

#### Scenario: 送信中に別のissueを開く
- **WHEN** issue Bの返答の欄に書きかけがある状態で、issue Aの返答を送り、応答が返る前にBを開く
- **THEN** 応答が返った後も、Bの欄には書きかけが残り、「送りました」は出ず、欄は押せる

#### Scenario: 送信中に移った先で失敗が返る
- **WHEN** issue Aの返答を送り、応答が返る前にBを開き、Aへの送信が失敗する
- **THEN** Bには誤りが出ず、失敗はトーストで出て、Aを開き直すと書きかけが残っている

### Requirement: 自動マージの取り消し後のマージのボタン
マージの結果が自動マージ待ちだったとき、WUIは、一覧に `auto_merge` が載るまで、そのボタンを「自動マージ待ち」として押せなくしなければならない（MUST）。
一覧に `auto_merge` が載った後は、WUIは、`auto_merge` だけでボタンの状態を決めなければならない（MUST）。取り消しや打ち切りで `auto_merge` が消えたら、ボタンは「マージ」に戻り、押せる。

#### Scenario: 自動マージを取り消す
- **WHEN** マージが自動マージ待ちになり、一覧に `auto_merge` が載った後、「自動マージを取り消す」で一覧から `auto_merge` が消える
- **THEN** 1件の表示のボタンは「マージ」に戻り、押せる

### Requirement: 経過時間の描き直し
WUIは、一覧、1件の表示、何も選んでいない画面に出す経過時間を、一覧が届かなくても1分ごとに描き直さなければならない（MUST）。

#### Scenario: 開いたまま時間がたつ
- **WHEN** 待ちになって1分未満のissueを一覧に出したまま、一覧が届かずに2分たつ
- **THEN** その行の時間は「2分前から待ち」になる

### Requirement: 完了の節の注記
WUIは、一覧の完了の節の見出しの下に`closeすると一覧から消えます。コメントすると作業を再開します`を1回だけ出さなければならない（MUST）。
完了の行とカードは、この注記を行ごとに出してはならない（MUST NOT）。

#### Scenario: 完了が2件ある
- **WHEN** 完了のissueが2件ある状態で一覧を開く
- **THEN** 注記は完了の節に1回だけ出る

### Requirement: 実行中の1件の案内
実行中のissueの1件の表示は、返答の欄の代わりに`実行中です。質問か完了になると、この画面が自動で切り替わります`を出さなければならない（MUST）。

#### Scenario: 実行中のissueを開く
- **WHEN** 実行中のissueを開く
- **THEN** 返答の欄は出ず、画面が自動で切り替わることの案内が出る

### Requirement: フォージへのリンクの名前
1件の表示の見出しのフォージへのリンクは、「フォージで開く ↗」と表示しなければならない（MUST）。読み上げの名前は「フォージで開く（新しいタブ）」でなければならない（MUST）。

#### Scenario: リンクを読み上げる
- **WHEN** スクリーンリーダーで1件の表示の見出しを読む
- **THEN** リンクは「フォージで開く（新しいタブ）」と読まれ、画面には「フォージで開く ↗」と出る
