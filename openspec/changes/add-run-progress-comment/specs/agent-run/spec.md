## ADDED Requirements

### Requirement: 実行中の進捗のコメント
エージェントは、`claude -p` を起動したら、その実行の進捗のコメントを1つ投稿しなければならない（MUST）。進捗のコメントには、マーカー（`state=progress`、同じ `run`）を付ける。着手のコメントとは別のコメントとし、着手のコメントは書き換えない。
実行の間、エージェントは1分ごとに進捗のコメントを書き換え、1行を足さなければならない（MUST）。1行には、時刻、経過時間、それまでに使ったツールの名前と回数、目的の1行を書く。目的の1行は、`claude -p` の最新のassistantのテキストの1行目を、120文字で切ったものとする。足す行が直前の行と同じ内容なら、足さない。
進捗のコメントに、実行したコマンドの中身、編集したファイルの名前、ツールの入力と出力を書いてはならない（MUST NOT）。
書き換えるたびに、エージェントは、結果のコメントと同じ秘密の検査と `comments.check_command` を通さなければならない（MUST）。秘密が見つかった行は、その旨を書いた行に置き換える。
進捗のコメントの投稿と書き換えに失敗しても、エージェントは実行を止めてはならない（MUST NOT）。

#### Scenario: 進み具合が足される
- **WHEN** 実行が3分続き、その間にEditとBashを使い、assistantのテキストが変わる
- **THEN** 進捗のコメントは1つだけで、時刻、経過時間、ツールの回数、目的の1行を持つ行が、1分ごとに足されている

#### Scenario: 変わらない間
- **WHEN** 1分の間に、ツールの回数も目的の1行も変わらない
- **THEN** 進捗のコメントに行は足されない

### Requirement: 進捗のコメントの削除
エージェントは、実行の結果のコメント（待ちか完了）を投稿したあとで、その実行の進捗のコメントを消さなければならない（MUST）。取り消し、時間切れ、異常な終了でも同じとする。
再起動のあとの回復で、エージェントは、自分が投稿した進捗のコメントのうち、実行中でない実行のものを消さなければならない（MUST）。

#### Scenario: 完了する
- **WHEN** 実行が完了し、完了のコメントが投稿される
- **THEN** その実行の進捗のコメントは消え、着手のコメントと完了のコメントが残る

#### Scenario: エージェントが落ちる
- **WHEN** 実行の途中でエージェントのプロセスが落ち、再起動する
- **THEN** 回復で結果のコメントが投稿され、残っていた進捗のコメントは消える
