# grilling 記録: add-permission-grants

背景：2026-11-15に、`gh:uskanda/smarternews` で `waiting(reason=permission)` が8件出た。拒否されたのは主に `git ls-tree`（6件）、`git fetch`（6件）、`git mv`（4件）、`git rm`（2件）、`git merge-base`（1件）である。gitはsandboxの外で動かすので（ADR-057）、許可の規則に無いサブコマンドはすべて拒否される。今の実装の実行の許可は `status`、`diff`、`log`、`add`、`commit`、`merge` だけである。ADR-045は、許可を設定ファイルにだけ書けるとし、受信箱のAPIとWeb表示からは変えられないと決めている。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 既定で足すgitのサブコマンド | 実装の実行と直す実行に、読むだけのもの（`ls-tree`、`ls-files`、`show`、`cat-file`、`merge-base`、`rev-parse`、`rev-list`、`blame`、`grep`、`shortlog`、`describe`）と、worktreeの中だけを変える `mv`、`rm`、`restore`、`stash` を足す。計画の実行には読むだけのものを足す。`checkout`、`switch`、`reset`、`branch`、`config`、`-c` は足さない | 第1ラウンド Q1 |
| `git fetch` | 今までどおり拒否する。system promptに、`origin/<base>` は実行の前にfetch済みだと書く | 第1ラウンド Q2 |
| WUIから足す許可の置き場所 | 追加の指示と同じく、設定のディレクトリの下にファイルで置く。全体、プロジェクト、issueの3つの単位を持つ。実行のたびに読み、設定ファイルの `allow_tools_extra` とつなげる | 第1ラウンド Q3 |
| 誰が許可を足せるか | `inbox.auth` のある構成では、3つの単位ともadminだけ。ない構成では、追加の指示と同じくWUIを開ける人なら誰でも。足すたびと外すたびに監査ログに残す | 第1ラウンド Q4 |
| WUIから足せる規則の制限 | 設定ファイルと同じ検査（空の項目、制限の無い `Bash`、拒否している操作）に加えて、`git config`、`git -c`、サブコマンドを限らないgit（`Bash(git *)` など）、ワイルドカードだけの規則を断る | 第1ラウンド Q5 |
| WUIの入口 | permission待ちのissueの詳細に、拒否された操作の一覧と許可を出し、範囲（このissue／このプロジェクト／全プロジェクト）を選ぶ。設定の画面に全体とプロジェクトの一覧と編集を置く。issueの詳細に、issue単位の一覧と外すボタンを置く | 第1ラウンド Q6 |
| 計画の実行への適用 | WUIから足した許可は渡さない。ファイルを書く実行（実装と直す実行）だけに渡す（ADR-045と同じ） | 第1ラウンド Q7 |
| 拒否から作る規則の候補 | 1つだけのコマンドなら、先頭の語とサブコマンドから候補を作る（`Bash(git ls-tree)` と `Bash(git ls-tree *)`）。候補は保存の前に編集できる。つないだコマンドには候補を出さず、規則では許可できないと出す。WUIの検査で断られる候補は出さない | 第2ラウンド Q8 |
| 許可したあとの再開 | 「許可して再実行」で、保存と、既存の「再実行する」の返信の投稿を続けて行う。「許可だけ」も選べる | 第2ラウンド Q9 |
| issue単位の許可の寿命 | 消さない。issueが閉じても残し、再び開かれたら、その実行に渡す。詳細の一覧から人が外す | 第2ラウンド Q10 |
| 端末が複数のとき | 追加の指示と同じ制限として受け入れ、文書に書く。受信箱のサービスの端末にない別の端末のエージェントには届かない | 第2ラウンド Q11 |
| CLIとアプリ | WUIだけにする。ファイルは手で編集してもよい。Androidのアプリには入れない | 第2ラウンド Q12 |
| 拒否された操作の読み取り元 | エージェントの最新の `waiting(reason=permission)` のコメントから読む。投稿者がエージェントであることを確かめ、「拒否された操作」の節の行を取り出す。中身はデータとして扱い、表示は文字列だけにする | 第3ラウンド Q13 |
