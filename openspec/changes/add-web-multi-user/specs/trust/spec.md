# Spec Delta

## ADDED Requirements

### Requirement: 同じアカウントの特例を使う構成
ADR-056の特例は、`<inbox.auth>` を書いていない構成でだけ使わなければならない（MUST）。この特例は、エージェントのアカウントが再開の印なしで付けた始めるラベルを、信頼するユーザーのものとして扱う。
`<inbox.auth>` を書いた構成では、エージェントのアカウントが付けた始めるラベルを、信頼するユーザーのものとして扱ってはならない（MUST NOT）。

#### Scenario: 認証を設定した構成で、エージェントのアカウントがラベルを付ける
- **WHEN** `<inbox.auth>` があり、エージェントのアカウントが再開の印なしで `agent:ready` を付ける
- **THEN** エージェントは実行を始めず、判定を監査ログに残す
