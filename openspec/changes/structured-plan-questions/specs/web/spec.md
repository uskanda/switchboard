## ADDED Requirements

### Requirement: 問いの図
最新の質問の問いの本文で、選択肢の組より前に `mermaid` の言語のコードブロックがあるとき、1件の表示は、それを図として描かなければならない（MUST）。図は、問いのカードの中の、本文と選択肢の組の間に置く。
1件の表示は、図を問いのカードの幅に収まるように縮めて描かなければならない（MUST）。
図を押したとき、1件の表示は、図を元の大きさでダイアログに開かなければならない（MUST）。ダイアログの中では、縦と横にスクロールできる。
図の中の `:::focus` の印を付けたノードを、1件の表示は、枠を太くして描かなければならない（MUST）。色は変えない。
OSが暗い配色を求める間、1件の表示は、図を暗いテーマで描かなければならない（MUST）。配色が変わったときは、描き直す。

#### Scenario: 図のある問い
- **WHEN** 本文と選択肢の間に `flowchart TD` の `mermaid` のコードブロックを持つ問いの待ちを開く
- **THEN** その問いのカードの、本文と選択肢の間に図が描かれ、コードブロックの文は出ない

#### Scenario: 図を拡大する
- **WHEN** 問いのカードの図を押す
- **THEN** 図が元の大きさでダイアログに開く

#### Scenario: 強調したノード
- **WHEN** `B:::focus` を含む図の問いの待ちを開く
- **THEN** Bのノードは、ほかのノードより太い枠で描かれる

### Requirement: 図を描かない場所
最新の質問の問いの図の位置にないMermaidのコードブロックを、1件の表示は図として描いてはならない（MUST NOT）。前のラウンドの質問、人のコメント、ほかのエージェントの投稿のMermaidは、コードとして描く。
図の種類が `flowchart`、`stateDiagram-v2`、`sequenceDiagram` のどれでもないとき、1件の表示は、その図を描いてはならない（MUST NOT）。
図が、行頭（空白を除く）の `classDef`、`style`、`linkStyle`、`click` か、`%%{` を含むとき、1件の表示は、その図を描いてはならない（MUST NOT）。

#### Scenario: 人のコメントのMermaid
- **WHEN** 人のコメントに `mermaid` のコードブロックがあるissueを開く
- **THEN** そのコードブロックは、図ではなくコードとして出る

#### Scenario: スタイルを変える図
- **WHEN** `style A fill:#f00` の行を含む図を持つ問いの待ちを開く
- **THEN** 図は描かれず、「図を描けませんでした」と、折りたたんだ元の文が出る

### Requirement: 図を描けなかったとき
図を描かないと決めたとき、または描くのに失敗したとき、1件の表示は、図の位置に「図を描けませんでした」を出し、図の元の文を折りたたんで置かなければならない（MUST）。

#### Scenario: 書き方の誤った図
- **WHEN** Mermaidの書き方の誤った `flowchart TD` の図を持つ問いの待ちを開く
- **THEN** 図の位置に「図を描けませんでした」が出て、折りたたみを開くと図の元の文が読める

### Requirement: 図を描く部品の読み込み
図のある問いを表示するまで、Web表示は、図を描く部品を読み込んではならない（MUST NOT）。

#### Scenario: 図の無い待ち
- **WHEN** 図の無い問いだけの待ちを開く
- **THEN** 図を描く部品は読み込まれない

### Requirement: 推奨の段落の頭の印
推奨の理由を推奨の選択肢の行の下に出すとき、1件の表示は、推奨の段落の頭の太字の `推奨：〈ラベル〉` か `Recommended: 〈label〉` を除いて理由を出さなければならない（MUST）。

#### Scenario: 構造化した推奨の段落
- **WHEN** 推奨の段落が `➡️` と太字の `推奨：B` で始まり、`読み込みが速くなる` が続く問いを開く
- **THEN** Bの行の下に `読み込みが速くなる` が出て、`推奨：B` は出ない

### Requirement: Web表示のCSP
`<switchboard-web>` は、すべての応答に、決まったContent-Security-Policyを付けなければならない（MUST）。
値は、次の5つを、この順に `; ` でつないだものとする。

- `default-src 'self'`
- `style-src 'self' 'unsafe-inline'`
- `frame-ancestors 'none'`
- `base-uri 'none'`
- `form-action 'self'`


#### Scenario: CSPの見出し
- **WHEN** 受信箱のWeb表示のページを読む
- **THEN** 応答のContent-Security-Policyは、`script-src` を緩めず、スタイルだけにインラインを許している
