# grilling 記録: structured-plan-questions

計画の質問の選択肢を構造として持たせ、問いごとに図を付けられるようにする計画である（issue `gh:uskanda/switchboard` #190）。#194（`plan-question-cards`）の問いのカードの上に作る。`add-web-plan-answers` の第1ラウンドQ1（選択肢はWeb表示が文字列から読み取り、宣言のスキーマは変えない）を、この変更で決め直す。

図の描き方は、決める前に実験で確かめた。Chromiumで、今のCSP（`default-src 'self'`）のままMermaid 12.2.0で描くと、図形と文字が黒く塗りつぶされる。`style-src 'self' 'unsafe-inline'` を足すと、違反なしに描ける。CSPを変えない回避策もあるが、図1つに70〜110件の違反の報告が出て、Mermaidの内部の作りに頼る。流れ図1つで読み込む量は、既定のelkのレイアウトで653 kB、`dagre` で213 kB（どちらもgzip）である。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| 選択肢の組の数 | 1問1組にする。軸が2つある問いは、別々の問いに分けるようプロンプトで指示する（これまでの200問はすべて1組だった） | 第1ラウンド Q1 |
| 選択肢の無い問い | 選択肢を必須にし、2個以上とする。どれでもない答えは、#194の「補足だけで答える」で書く | 第1ラウンド Q2 |
| 推奨の持ち方 | 推奨のラベル（`recommended`）と理由の文（`reason`）に分ける。ラベルが選択肢から外れたら、出力の誤りとして実行を失敗にする | 第1ラウンド Q3 |
| コメントに書く形 | switchboardが決まった形で書く。選択肢は `A: 文` を1行に1つ、推奨は `➡️ **推奨：A**` で始まる段落にする。今のWeb表示の読み取り方で読めるので、隠しのJSONは埋めない | 第1ラウンド Q4 |
| 図を付ける問い | 任意にする。流れ、状態の移り変わり、部品の関係、画面の配置を問う問いで、図が理解を助けるときだけ付けるよう、プロンプトに目安を書く | 第1ラウンド Q5 |
| 図の種類と大きさ | Mermaidの `flowchart`、`stateDiagram-v2`、`sequenceDiagram` に限る。外れた図は捨てて本文だけを投稿する。プロンプトで、ノードは8個まで、ラベルは短く、縦向き（`TD`）と指示する。比較の表は本文のMarkdownの表で書かせる | 第1ラウンド Q6 |
| 図を描けなかったとき | Web表示は「図を描けませんでした」と出し、図の元の文を折りたたみで見せる | 第1ラウンド Q7 |
| 図の置き場所とスマホでの見せ方 | 問いのカードの中で、本文の後、選択肢の前に置き、カードの幅に合わせて縮める。押すと、元の大きさでダイアログに開き、縦横にスクロールできる | 第1ラウンド Q8 |
| 図の描き方とCSP | CSPに `style-src 'self' 'unsafe-inline'` を足し、Mermaidの標準の描き方を使う。ADR-055の「CSPを緩めない」を、新しいADRで改める | 第2ラウンド Q9 |
| 図の中身の制限 | `classDef`、`style`、`linkStyle`、`click`、`%%{` を含む図を捨て、本文だけを投稿し、監査ログに残す。強調には、switchboardが用意する `:::focus` だけを使わせる。Mermaidは `securityLevel: 'strict'` で動かす | 第2ラウンド Q10 |
| Mermaidの版と読み込み方 | `mermaid@12.2.0` に固定する。図のある問いを開いたときだけ読み込み、`vendor` のまとめから外す。レイアウトは `dagre` にする | 第2ラウンド Q11 |
| ダークモードでの図の色 | OSのダークモードに合わせ、暗いときは `dark`、明るいときは `neutral` のテーマで描く。OSの設定が変われば描き直す | 第2ラウンド Q12 |
| 選択肢のラベルを振る側 | エージェントは選択肢の文だけを並べ、switchboardが順にA、B、C…と振る。推奨はそのラベルで書かせる。選択肢は2〜6個とする | 第3ラウンド Q13 |
| Web表示がMermaidを描く場所 | 最新の質問の問いのカードの図の位置だけで描く。Web表示も第2ラウンドQ10と同じ語を含む図は描かず、元の文を出す。ほかの場所のMermaidは、今までどおりコードとして出す | 第3ラウンド Q14 |
| `:::focus` の見た目 | 枠を `primary` の2pxにするだけで、色は付けない | 第3ラウンド Q15 |
