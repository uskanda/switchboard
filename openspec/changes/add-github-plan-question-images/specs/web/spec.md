## MODIFIED Requirements

### Requirement: 問いの画像
最新の質問の問いのカードでは、1件の表示は、問いの画像と選択肢の画像を受信箱のAPIから取って描かなければならない（MUST）。問いの画像は本文と選択肢の組の間にある画像、選択肢の画像は選択肢の行の直後の画像である。描く画像は、次のURLを指すものだけとする。GitLabのissueでは、そのプロジェクトのアップロードのURLである。GitHubのissueでは、`https://github.com/user-attachments/assets/` の下のURLである。
問いの画像は、本文と選択肢の組の間に置く。選択肢の画像は、その選択肢の下に置く。
1件の表示は、画像をカードの幅に収まるように縮めて描き、押したときは元の大きさでダイアログに開かなければならない（MUST）。ダイアログの中では、縦と横にスクロールできる。
画像を取れなかったとき、1件の表示は、画像の代わりに、今までどおり画像へのリンクを出さなければならない（MUST）。
最新の質問の問いのカードの外の画像は、今までどおりリンクとして出す。

#### Scenario: 選択肢の画像
- **WHEN** 選択肢AとBの行の直後にGitLabのアップロードの画像を持つ問いの待ちを開く
- **THEN** AとBの選択肢の下に、それぞれの画像が縮めて描かれる

#### Scenario: GitHubの問いの画像
- **WHEN** 本文と選択肢の組の間に `https://github.com/user-attachments/assets/<uuid>` の画像を持つ、GitHubのissueの問いの待ちを開く
- **THEN** その画像が、受信箱のAPIから取って縮めて描かれる

#### Scenario: 非公開のリポジトリで読めない画像
- **WHEN** 受信箱のAPIが、GitHubの問いの画像に404を返す
- **THEN** 画像の位置に、画像へのリンクが出る

#### Scenario: 前のラウンドの画像
- **WHEN** 前のラウンドの質問のコメントにGitLabのアップロードの画像がある待ちを開く
- **THEN** その画像はリンクとして出る
