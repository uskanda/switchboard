# Proposal

## Why

プロジェクトでまとめる表示では、サブグループの見出しがプロジェクトの参照とフォージのバッジを出している。それでも各行がまた参照`o/r#12`、アイコン、バッジを出すので、同じ情報が重なり、タイトルが読みにくい（issue #139）。行からプロジェクトの表示を除き、番号だけをタイトルの左に残す。

## What Changes

- プロジェクトでまとめる間、サブグループの中の行は、プロジェクトのアイコン、参照、フォージのバッジを出さない
- その行は、issueの番号（例：`#12`）をタイトルの左、同じ行の先頭に出す。番号は`mono-sm`の`muted`にする
- カード（640px未満と、1024px以上の左のペイン）と表（640〜1024px）の両方を変える
- まとめない表示の行は今のまま（アイコン、参照、バッジ、タイトル）にする
- 前回の変更2026-11-03-group-inbox-by-projectで決めた「サブグループの中の行は参照とバッジを出す」を覆す

## Capabilities

### New Capabilities

新しい能力は無い。

### Modified Capabilities

- `web`: サブグループの中の行の表示を、「一覧の節のプロジェクトのサブグループ」の要件で書き換える

## Impact

- `web/ui/src/components/InboxList.tsx`
- 画面のテスト`web/ui/src/pages/grouping.test.tsx`
- `DESIGN.md`の「プロジェクトのサブグループ」の項
- Goのコード、API、CLIは変わらない
