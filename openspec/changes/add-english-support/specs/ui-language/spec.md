# Spec Delta

## Purpose

Web表示、Androidのアプリ、紹介ページの文言を日本語と英語で用意し、読み手ごとにどちらで出すかを決める。言語ごとの文の形も定める。

## ADDED Requirements

### Requirement: Web表示の言語の決め方
言語の選択が「自動」の間、WUIは、ブラウザの優先する言語の並びを先頭から見て、最初に現れた日本語か英語を表示の言語にしなければならない（MUST）。
言語の選択が「自動」の間、優先する言語の並びに日本語と英語のどちらも無いとき、WUIは英語で表示しなければならない（MUST）。
ブラウザに保存した言語の選択が無いとき、WUIは選択を「自動」として扱わなければならない（MUST）。

#### Scenario: 日本語のブラウザ
- **WHEN** 優先する言語の並びが `ja-JP`、`en-US` のブラウザで、言語の選択を保存していないままWUIを開く
- **THEN** 画面は日本語で表示される

#### Scenario: 英語より後ろに日本語がある
- **WHEN** 優先する言語の並びが `fr-FR`、`en`、`ja` のブラウザで、言語の選択が「自動」のままWUIを開く
- **THEN** 画面は英語で表示される

#### Scenario: どちらの言語も無い
- **WHEN** 優先する言語の並びが `fr-FR` だけのブラウザで、言語の選択が「自動」のままWUIを開く
- **THEN** 画面は英語で表示される

### Requirement: 言語の選択
WUIは、設定の画面の表示の節に、言語の選択肢「自動」「日本語」「English」を置かなければならない（MUST）。
言語の選択肢を選んだとき、WUIは、画面を読み直さずに、選んだ言語で表示し直さなければならない（MUST）。
言語の選択肢を選んだとき、WUIは、選択をブラウザに保存しなければならない（MUST）。次にWUIを開いたとき、WUIは保存した選択に従わなければならない（MUST）。
WUIは、言語の選択をサーバーに送ってはならない（MUST NOT）。

#### Scenario: 英語を選ぶ
- **WHEN** 日本語で表示しているWUIの設定の画面で、言語に「English」を選ぶ
- **THEN** 画面は読み直されずに英語で表示し直され、次に開いたときも英語で表示される

#### Scenario: 自動に戻す
- **WHEN** 言語に「English」を選んだ後、優先する言語が `ja-JP` のブラウザで「自動」を選ぶ
- **THEN** 画面は日本語で表示される

### Requirement: ログインの画面の言語の切り替え
ログインの画面は、今の表示の言語でないほうの言語へ切り替えるボタンを出さなければならない（MUST）。ボタンの文は、切り替え先の言語で書かなければならない（MUST）。
言語の切り替えのボタンを押したとき、WUIは、その言語を選択としてブラウザに保存し、ログインの画面をその言語で表示し直さなければならない（MUST）。

#### Scenario: 英語のログインの画面から日本語へ
- **WHEN** 英語で表示しているログインの画面で、「日本語」のボタンを押す
- **THEN** ログインの画面は日本語で表示され、言語の選択として日本語が保存される

### Requirement: 文書の言語の属性
WUIは、文書の `lang` の属性を、表示の言語（`ja` か `en`）に合わせなければならない（MUST）。

#### Scenario: 英語で表示する
- **WHEN** WUIを英語で表示する
- **THEN** `html` の要素の `lang` は `en` になる

### Requirement: 文言の言語
WUIは、画面の文言を表示の言語で出さなければならない（MUST）。ここでいう文言は、見出し、ボタン、リンク、案内、誤り、トースト、支援技術向けの名前、タブのタイトルを含む。
`web`、`web-auth`、`web-users` の要件が引く日本語の文言は、日本語で表示するときの文言である。英語で表示するとき、WUIは、同じ意味の英語の文言を出さなければならない（MUST）。
WUIは、issueの本文、コメント、エージェントの投稿、フォージと設定から来た値、サーバーが返す誤りの文を、表示の言語に訳してはならない（MUST NOT）。

#### Scenario: 英語の返答の欄
- **WHEN** 英語で表示しているWUIで、質問で待っているissueを開く
- **THEN** 返答の欄の名前と送るボタンは英語で表示され、エージェントの質問の本文はそのまま表示される

#### Scenario: サーバーの誤りの文
- **WHEN** 日本語で表示しているWUIで、返答の送信がサーバーの英語の誤りの文で断られる
- **THEN** 日本語の誤りの文に続けて、サーバーの英語の文がそのまま表示される

### Requirement: 英語の数と時間の書き方
英語で表示するとき、WUIは、数を含む文言で、数が1なら単数形、それ以外なら複数形を使わなければならない（MUST）。
英語で表示するとき、WUIは、経過時間と相対時間を英語の語順で出さなければならない（MUST）。

#### Scenario: 待ちが1件
- **WHEN** 英語で表示しているWUIで、待ちのissueが1件だけある
- **THEN** 件数は単数形で表示される

#### Scenario: 5分前から待っている
- **WHEN** 英語で表示しているWUIで、5分前から待っているissueを一覧に出す
- **THEN** 時間の欄は、5分前から待っていることを英語の語順で表示する

### Requirement: 投稿する文の言語
「この内容で返答」と「再実行する」がissueに投稿する文は、投稿したときの表示の言語で書かなければならない（MUST）。
英語で表示するとき、「この内容で返答」が送る文は、問いごとに1行、`Q<番号> <題>: <答え>` の形でなければならない（MUST）。2組以上の問いでは、見出しのある組を `<見出し>: <ラベル>` として、`; ` でつなぐ。自由記述があれば、そのあとに `. Note: <自由記述>` を付ける。答えの無い問いは `No answer` とし、返答の欄の文は `Overall note:` の行のあとに置く。

#### Scenario: 英語で計画の質問に答える
- **WHEN** 英語で表示しているWUIで、Q1にBを選び、自由記述に `keep it small` と書いて「この内容で返答」を押す
- **THEN** `Q1 <題>: B. Note: keep it small` の行が投稿される

#### Scenario: 英語で再実行する
- **WHEN** 英語で表示しているWUIで、理由が `error` の待ちのissueの「再実行する」を押す
- **THEN** 再実行を頼む英語の決まった文が1回投稿される

### Requirement: Androidのアプリの言語
アプリは、端末の言語が日本語のとき日本語で、それ以外のとき英語で、自身の画面の文言を出さなければならない（MUST）。
アプリは、通知のボタン、通知のチャンネルの名前、アプリが作る通知の文を、端末の言語で出さなければならない（MUST）。
アプリは、WebViewで開くWeb表示に、言語を指定してはならない（MUST NOT）。

#### Scenario: 英語の端末
- **WHEN** 言語が英語の端末で、計画の承認待ちの通知を受ける
- **THEN** 通知の承認のボタンは英語で表示される

#### Scenario: 日本語の端末
- **WHEN** 言語が日本語の端末で、アプリの接続先の画面を開く
- **THEN** 画面の文言は日本語で表示される

### Requirement: 紹介ページの言語
紹介ページは、英語の版をルート（`/`）に、日本語の版を `/ja/` に置かなければならない（MUST）。
紹介ページの各版は、もう一方の版へのリンクと、両方の版を指す `hreflang` の代替の宣言を持たなければならない（MUST）。
紹介ページは、閲覧者の言語によって、別の版へ自動で転送してはならない（MUST NOT）。

#### Scenario: ルートを開く
- **WHEN** 日本語のブラウザで紹介ページのルートを開く
- **THEN** 英語の版が表示され、日本語の版へのリンクがある
