## MODIFIED Requirements

### Requirement: 順番待ちの表示
WUIは、一覧の「実行中」の節の下に「順番待ち」の節を出さなければならない（MUST）。各行には、順番待ちの印、当たった上限、順番待ちの経過時間を出す。
順番待ちの理由が利用上限かクオータで、再開の時刻があるとき、行の当たった上限には、その時刻を添えなければならない（MUST）。
順番待ちのissueがあるとき、WUIは、ヘッダに順番待ちの件数も表示しなければならない（MUST）。
順番待ちのissueを選んだとき、1件の表示は、順番待ちであることと経過時間を示さなければならない（MUST）。
`agent:waiting` が付いた順番待ちのissueでは、1件の表示は、返答の欄を今までどおり使えるようにしなければならない（MUST）。

#### Scenario: 順番待ちのissueを選ぶ
- **WHEN** 順番待ちの節の行を選ぶ
- **THEN** 右のペインに、順番待ちの印と経過時間、順番待ちのコメントが出る

#### Scenario: 返答の待ちが順番待ちになる
- **WHEN** 開いている待ちのissueが、返答のあとで順番待ちになる
- **THEN** 一覧ではその行が順番待ちの節に移り、1件の表示の返答の欄は使えるままである

#### Scenario: 利用上限の順番待ち
- **WHEN** 理由が `limit` で、再開の時刻のある順番待ちの行がある
- **THEN** その行に「利用上限に達しています」と、再開の時刻が出る
