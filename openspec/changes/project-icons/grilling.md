# grilling 記録: project-icons

issue `gh:uskanda/switchboard` #105の変更である。Webの受信箱で、プロジェクトのアイコンを参照のそばに出す。計画の段階で、エージェントがissueのコメントで質問し、issueの持ち主が答えた。そのやり取りをここに写す。

## 決定

| 決定 | 選択 | 出典 |
|---|---|---|
| アイコンをどこから取るか | 既定ではフォージから取る。GitLabはプロジェクトのアバター（無ければグループのアバター）、GitHubはオーナーのアバターを使う。config.yamlのプロジェクトに`icon`があれば、そちらを優先する | issue #105 Q1（D） |
| 画像をブラウザへどう届けるか | inboxサービスがフォージのトークンで画像を取り、端末に保存する。switchboard-webは自分のURLで返す。CSP（`default-src 'self'`）は変えない | issue #105 Q2（A） |
| アイコンを出す場所 | IssueRefを使うすべての場所に出す。ネイティブの`<select>`には出さない | issue #105 Q3（A） |
| 大きさ、位置、取れないとき | 参照の前に16pxの角丸の画像を置き、`alt=""`にする。取れないときとまだ取っていないときは、プロジェクト名の頭文字を出す同じ大きさの丸を`muted`の地で置く | issue #105 Q4（B） |
| `icon`の書き方 | `https://`で始まれば画像のURL、`/`か`~/`で始まればその端末の画像ファイル、それ以外は絵文字1文字（書記素1つ）。2文字以上は設定の誤りにする | 計画（コメント6593685367） |
| 絵文字の出し方 | 画像にせず、文字のまま頭文字の丸の場所に出す。inboxサービスは設定の絵文字を参照ごとにまとめて返す | 計画（コメント6593685367） |
| 画像の検め | PNG、JPEG、GIF、WebPだけを先頭のバイトで判定して受け付け、SVGは受け付けない。256KiBまで。保存は24時間、取れなかったことは1時間覚える | 計画（コメント6593685367） |
| 計画の承認 | 計画を変えずに承認 | issue #105 コメント6594281594（`/ok`） |
